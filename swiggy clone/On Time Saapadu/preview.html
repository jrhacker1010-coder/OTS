Your food delivery application has been successfully created! To run it locally:

📋 Quick Start Instructions:

1. Install Dependencies

cd "On Time Saapadu/backend"
npm install

cd "../frontend"
npm install

2. Start MongoDB

Make sure MongoDB is running on your system

3. Seed Database

cd "On Time Saapadu/backend"
node seed.js

4. Start Servers

Open two terminal windows:

# Terminal 1 (Backend):
cd "On Time Saapadu/backend"
npm run dev

# Terminal 2 (Frontend):
cd "On Time Saapadu/frontend"
npm run dev

5. Access Your App

🌐 Frontend: http://localhost:5173
🔧 Backend API: http://localhost:5000
